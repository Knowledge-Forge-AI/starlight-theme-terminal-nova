## Overview Details

The overview route exercises the catalog banner Hero layout when rendered by the catalog-enabled Starlight theme plugin.

### Architectural Principles

1. **Proportional Typography**: Readable system sans prose at 1.65 line height.
2. **Disciplined Chrome**: Monospace navigation and code boundaries.
3. **Contrast Fidelity**: Verified WCAG contrast diagnostics across light and dark modes.
4. **Offline Isolation**: Zero external network requests at runtime.
