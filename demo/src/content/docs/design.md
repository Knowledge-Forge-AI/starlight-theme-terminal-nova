## Forge Console

Warm-white light pages and near-black dark pages carry a compact sans-serif reading system. Orange appears in navigation and links, with darker derived orange for small text on light surfaces. The approved title frame adds a structural cue at the page boundary. Code stays monospace; body text does not.

## Nova Observatory

Violet links, softer panels, a wider column, and serif prose favor essays and long-form notes. It retains the default title. The result is a quieter editorial direction with less terminal character.

## Provisional selection

Forge Console is the working direction for technical documentation. The retained installed-package renders and measurements record the comparison. The next external review decides visual acceptance; neither the theme nor this demonstration is a public release.

## Brand and source

The implementation is independent of the legacy fork. Only the approved, unmodified Nova Ingot marks and favicon artwork are reused for official project presentation. First-party code retains AGPL-3.0-or-later with separately available commercial terms; artwork permissions and theme data provenance remain separate.
