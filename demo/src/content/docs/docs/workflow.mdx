## Engine Pipeline

Stellar Burst compiles canonical scene JSON into local SVG assets. Stellar Loom compiles a canonical theme into the installable Starlight package. Nebular Fusion supplies the authoring, verification, and design-evidence workbench. The demo assembles the two generated outputs; neither engine embeds the other.

## Read the figures

1. **Scene JSON → Burst → SVG:** the scene stays editable; the SVG is generated output.
2. **Theme specification → Loom → package:** the consumer installs the generated package through npm.
3. **Nebular → evidence:** briefs, candidates, verification and adoption remain traceable.
4. **Site assembly:** consumer-owned content combines local graphics with the installed theme.

The technical callout uses bounded geometry, resolved colors and local glyph paths. No remote fonts, raster images or executable configuration belong in these canonical inputs.
