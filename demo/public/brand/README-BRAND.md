# Terminal Nova identity artwork in the Starlight Theme Terminal Nova demo

This directory distributes four existing Nova Ingot outputs from the
[Theme Forge Terminal Nova brand collection](https://github.com/Knowledge-Forge-AI/theme-forge-terminal-nova/blob/461d9add96ed6c04b341e31305697a9046eed1a8/README-BRAND.md).
They retain their original geometry, colors and surface treatments.
The public name of this consumer is Starlight Theme Terminal Nova; this
reference does not rename or redirect the source brand project. The current
social metadata uses the separate, text-only `sttn-social.svg` and generated
`sttn-social.png`; these are independent site assets, not additional approved
Nova Ingot mark treatments. The existing `../art/nova-social.svg` remains a
historical promotional example and is not used for current metadata.
